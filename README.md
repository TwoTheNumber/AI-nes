# AI-nes
A emulator built in python for the NES built by AI.

# CONTROLS
A for left
D for right
W for up.
S for down.
R for select.
Y for start.
K for a. (also X works for some reason)
; for b.

# ISSUES
audio occasionally skips. (v1.0.0 and onward) 
in some games audio is glitched (v1.0.1 and onward) (only tested on smb 3 and famidash.)
